# calculateur

Projet d'application Flutter vierge.

## Prérequis

- [Flutter SDK](https://docs.flutter.dev/get-started/install) installé et configuré dans votre variable d'environnement `PATH`.

## Lancement

Pour installer les dépendances du projet :
```bash
flutter pub get
```

Pour lancer l'application sur un appareil ou simulateur connecté :
```bash
flutter run
```
